# Card Layout

Cards group related content and actions about a single subject.

## Surface

Cards use `--ds-color-surface-default`, a `--ds-color-border-default` border and
`--ds-radius-200` corners.

## Spacing

Stack cards with `--ds-space-200` and separate page sections with `--ds-space-400`.
